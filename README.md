# WSS2 docs

Documentation for **Manara**, the Android app that rates Wi-Fi networks before you connect and
checks connected networks for Evil Twin and man-in-the-middle signs. This repository holds the
`docs/` folder from the project's main (private) repository.

| File | What it covers |
| --- | --- |
| [`docs/Testing_Plan.md`](docs/Testing_Plan.md) | The four-phase testing plan |
| [`docs/Testing_Section_Requirements.md`](docs/Testing_Section_Requirements.md) | What the report's testing section needs, and what is missing |
| [`docs/Testing_Section_Template.md`](docs/Testing_Section_Template.md) | Draft of the testing section, with placeholders |
| [`docs/Demo_Checklist.md`](docs/Demo_Checklist.md) | Step-by-step demo script |
| [`docs/Stage5_Scoring_Policy.md`](docs/Stage5_Scoring_Policy.md) | How the connection check combines its results into a score |
| [`docs/lab/`](docs/lab/README.md) | Test access point setup (hostapd and dnsmasq) |
| [`docs/design/`](docs/design/README.md) | Design mockups |
| [`docs/screenshots/`](docs/screenshots) | App screenshots |

Attack testing is done only in an isolated lab, on equipment the team owns.
